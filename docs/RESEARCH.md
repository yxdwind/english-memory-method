# 英语篇章背诵法 · 实证研究设计

> **目的**：把 skill 的"比传统方法更好"从**信仰**变成**数据**。
> **状态**：研究协议草案（v0.1 · 2026-10-01）—— 待合作研究者 / IRB 审批后正式启动。
> **核心目标**：N=20 小规模对照实验，为后续多中心 / 大样本研究提供效应量估计与样本量计算依据。

---

## 1. 研究问题与假设

### 1.1 主要研究问题（RQ）
> 在保持期（D4-D7）不接触材料的前提下，使用本 skill 训练的受试者，**第 7 天的默写准确率**是否显著高于使用传统 shadowing（50 遍法）训练的受试者？

### 1.2 假设

| ID | 假设 | 方向 | 显著性阈值 |
|---|---|---|---|
| H1 | 实验组 D7 默写准确率显著高于对照组 | 单尾 | α = 0.05 |
| H2 | 实验组主观难度评分（反向计分）显著低于对照组 | 单尾 | α = 0.05 |
| H3 | 实验组在 D7 重测速度显著快于 D1 首测速度（对照组反之） | 双尾 | α = 0.05 |

### 1.3 探索性分析
- 实验组 / 对照组的"卡壳率"与 SM-2 ef 衰减斜率的相关性
- 段内高频词 vs 低频词的默写错误分布
- 训练期间放弃次数与最终准确率的相关系数

---

## 2. 样本

### 2.1 样本量
- **N = 20**（10 实验组 + 10 对照组）
- 选择依据：N=20 适合作为**可行性验证（pilot study）**，主要目的是：
  - 验证流程可行性（招募 / 材料 / 测量是否顺畅）
  - 估算效应量（Cohen's d）
  - 为后续大样本研究提供样本量计算（power analysis）

### 2.2 受试者入选标准
| 项目 | 标准 | 验证方式 |
|---|---|---|
| 年龄 | 18-35 岁 | 自报 |
| 英语水平 | CET-6 ≥ 425 / IELTS ≥ 6.5 / TEM-4 ≥ 60 | 提交成绩单截图 |
| 学习动机 | 自愿参与，非付费受试者 | 知情同意书 |
| 健康状态 | 无记忆障碍 / 失眠 / 抑郁筛查阳性 | PHQ-9 + GAD-7 简短筛查 |
| 设备 | 电脑 / 平板（能跑 Chrome / Edge / Safari 最新版） | 自报 |

### 2.3 排除标准
- 近 6 个月内有专业记忆训练（如记忆锦标赛 / Anki 高级用法）
- 英语母语者或双语者
- 实验期间（14 天）作息不规律（夜班 / 跨时区出差）

### 2.4 配对分组
- 按**英语水平**（高 / 中 / 低三档，每档 ~7 人）+ **性别**（男女各半）配对
- 配对后随机分入实验组 / 对照组（每对 2 人，1 实验 1 对照）

---

## 3. 材料

### 3.1 文本选择
- **来源**：选自 New Scientist / Scientific American / The Atlantic 等科普 / 学术媒体
- **长度**：200 词（±10 词）
- **难度**：
  - Flesch Reading Ease：60-70（标准难度）
  - Flesch-Kincaid Grade：10-12
  - 词频中位数：COCA 7000 词频表 4001-7000 档位（即"中高频"）
- **话题**：避开受试者专业领域（如：不要选心理学论文给心理学专业）
- **句长**：平均 18-22 词 / 句
- **结构**：3 段（总-分-总），8-12 句

### 3.2 翻译
- 提供**中文译文**（受试者母语为中文）
- 译文由英语专业 MTI 翻译 + 母语审校，保证准确
- 译文附在原文下方（受试者自选是否参考）

### 3.3 录音（对照组用）
- 选 BBC / VOA 同难度段落的标准发音录音
- 语速：每分钟 130-150 词（中等语速）
- 受试者用录音 + 文本做影子跟读，不限遍数但建议 30-50 遍

## 4. 流程（14 天）

```
D0  评估 + 知情同意 + 基线测试
D1  训练 Day 1（实验组 / 对照组分头进行）
D2  训练 Day 2
D3  训练 Day 3
D4  保持期开始（不接触材料）
D5  保持期
D6  保持期
D7  D7 测试（默写 + 主观 + 重测速度）
```

### 4.1 D0 评估（约 30 分钟）
1. 知情同意书签署（电子版）
2. 基线英语水平测试（5 分钟选词填空 / 短文阅读题）
3. 学习风格问卷（VARK 简短版）
4. 设备检查 + 操作演练（受试者自己跑一次 skill / 录音练习）
5. 发放材料：实验组给 `research-template.html`；对照组给文本 + 录音

### 4.2 训练期 D1-D3（每组 ~60-90 分钟 / 天）

**实验组**（用本 skill）：
- 打开 `assets/research-template.html`（受试者版简化模板）
- 完成：原文精读 → 关键词链式化 → 复述 5 级阶梯 → 挖空自测
- 不强制使用影子跟读，但允许
- 记录：训练用时 / 各步骤用时 / 卡壳句号

**对照组**（传统 shadowing）：
- 第一步：先听录音 3 遍，不看文本
- 第二步：看文本 + 跟读录音（影子跟读 50 遍，分 5 天，每天 10 遍）
- 第三步：尝试背诵（按句 → 按段 → 按全文）
- 不允许使用本 skill 的任何工具
- 记录：每天跟读遍数 / 尝试背诵次数 / 卡壳句号

### 4.3 保持期 D4-D7（不接触材料）
- 受试者不接触材料、录音或工具
- 每天 1 条简短推送（提醒"不要复习"）

### 4.4 D7 测试（约 45 分钟）

| 顺序 | 内容 | 时长 | 测量 |
|---|---|---|---|
| 1 | 默写（不参考） | 15 min | 主要指标：默写准确率 |
| 2 | 主观难度评分 | 2 min | 次要指标：5 分李克特量表 |
| 3 | 重测速度 | 10 min | 次要指标：再次背诵全文用时 |
| 4 | 学习体验访谈 | 20 min | 质性数据 |

## 5. 测量指标

### 5.1 主要指标（M1）
**D7 默写准确率**

评分方法（按句）：
- **4 分**：与原文完全一致（大小写 / 标点不敏感）
- **3 分**：错 1-2 个词
- **2 分**：错 3-5 个词
- **1 分**：错 > 5 个词或漏句
- **0 分**：完全空白或与原文无关

总分 = Σ 句分 / (句数 × 4) × 100%，即百分制。

### 5.2 次要指标
- **S1**：训练总用时（D1+D2+D3）
- **S2**：主观难度评分（1-5 分李克特，分数越低越好）
- **S3**：D7 重测速度（背诵全文用时，秒）
- **S4**：放弃次数（受试者主动放弃训练的天数）

### 5.3 探索性指标
- 卡壳率 = 弱评卡数 / 总评卡数
- SM-2 ef 衰减斜率（仅实验组有）
- 段内词频与错误率的相关性（高频词 vs 低频词）

## 6. 统计方法

### 6.1 主分析
- **Welch's t 检验**（不假设方差齐性）
- **Cohen's d**（效应量）
- **95% CI**（差值的置信区间）
- 单尾 α = 0.05

### 6.2 假设检验对应
- H1 → M1 用 Welch's t
- H2 → S2 用 Mann-Whitney U（小样本非正态）
- H3 → (S3_D7 - S3_D1) 差值用配对 t

### 6.3 探索性分析
- Pearson 相关（卡壳率 vs ef 斜率）
- 词频分段错误率（ANOVA）

### 6.4 效应量解读（Cohen's d）
- |d| < 0.2：微小
- 0.2 ≤ |d| < 0.5：小
- 0.5 ≤ |d| < 0.8：中等
- |d| ≥ 0.8：大

### 6.5 多重比较
- 主分析 3 个假设不调整（预设）
- 探索性分析用 Benjamini-Hochberg FDR (q = 0.05)

### 6.6 样本量计算（为后续研究）
即便 N=20 pilot 不足以做正式功效分析，**仍可输出效应量估计**。后续研究：
- 期望 d = 0.5（中等） → 需要每组 n ≈ 64（α=0.05, power=0.8）
- 期望 d = 0.8（大） → 需要每组 n ≈ 26

## 7. 数据采集

### 7.1 数据格式（JSON）

详见 `tests/fixtures/research-protocol.json`。

核心 schema：
```json
{
  "subject_id": "P01",

  "training_log": [
    { "day": 1, "minutes": 75, "weak_sentences": [3, 5], "shadow_used": false }
  ],
  "d7_recall": {
    "transcript": "...",
    "score_per_sentence": [4, 3, 4, 2, ...],
    "total_pct": 78.5
  },
  "subjective": { "difficulty": 2, "enjoyment": 4 },
  "retest_speed_sec": 240
```

### 7.2 数据匿名化
- 受试者仅记录 `subject_id`（P01-P20）+ 组别
- 不记录姓名 / 学号 / 邮箱 / IP
- 知情同意书单独保存（受试者签名的电子版）
- 数据存储在加密硬盘，保留 5 年后销毁

### 7.3 数据导出
- 受试者每天结束时点"导出今日数据"按钮（research-template.html 顶部）
- 浏览器下载 `subject_P01_day1.json`
- 受试者通过加密渠道上传到研究者服务器

## 8. 伦理

### 8.1 知情同意书要点
- 研究目的：评估 skill 的有效性
- 参与时长：14 天
- 风险：极低（无侵入性操作）
- 收益：完成全部 14 天后受试者获得一份个性化学习建议 + 50 元人民币感谢费
- 退出权：可随时退出，已采集数据销毁
- 数据使用：仅用于本研究，不商业化
- 联系方式：PI 邮箱 + IRB 编号

### 8.2 隐私保护
- 不采集 IP / 设备指纹
- 数据匿名化（P01-P20）
- 不公开受试者原始数据（仅公开聚合统计）
- 受试者可要求查看自己数据 + 删除请求

### 8.3 风险评估
- **极低风险**：纯认知任务，无侵入性操作
- **潜在不适**：长时间屏幕使用（建议每 30 分钟休息 5 分钟）
- **数据泄露风险**：匿名化 + 加密存储 + 5 年销毁
