## 第三幕：演示抓到真 bug → v2.42.1 修复

**现象**：🧮 切到 FSRS 后，任何 main 侧 `save(state)`（如阶梯点击）会用内存快照全量覆写进度，
抹掉 02-sr `patch` 写入的 `srAlgo` 与转换后的 `sr`。

**修复三件套**（v2.42.1，cc1af9d）：
1. `fresh()` 常驻 `srAlgo:'sm2'` 字段（内存态始终携带）
2. 02-sr `switchAlgo` 改经 `window.__emmAlgoSync(algo, srObj)` 钩子同步主内存 + 主 save 全量写（无 main 环境退回 patch）
3. qa-v239 新增 2 项回归护栏（main save 后 srAlgo 幸存 + ladder 同次写入互不覆盖）

**真机复验**：切换 → 阶梯保存 → **重载页面，FSRS 模式完整幸存**；FSRS 评卡排期 due=今天+3 天。
