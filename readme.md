## 🚀 快速开始

**Windows（PowerShell）**：

```powershell
irm https://cdn.jsdelivr.net/gh/yxdwind/english-memory-method@main/install.ps1 | iex
```

**macOS / Linux**：

```bash
curl -fsSL https://cdn.jsdelivr.net/gh/yxdwind/english-memory-method@main/install.sh | bash
```

**🌐 在线体验（无需安装）**：[github.io 样例站](https://yxdwind.github.io/english-memory-method/)——真实生成的方案，打卡 / 听写 / 影子跟读点开即用。

**Claude Code（零命令行）**：

```
/plugin marketplace add yxdwind/english-memory-method
/plugin install english-memory-method
```

**npm / npx**：

```bash
npx english-memory-method
```

> 安装器自动探测本机**全部已装平台**并逐一装入（16+ 平台别名见[平台支持](#-平台支持)）。
> jsdelivr 不通时换官方源：`irm https://raw.githubusercontent.com/yxdwind/english-memory-method/main/install.ps1 | iex`

**触发**：丢一篇英语文章 + 一句"出背诵方案"（或"出记忆技巧"）。装完无需重启。

### 🔒 可审计 / 离线安装（安全敏感环境）

若所在组织禁止 `irm | iex` / `curl | bash` 等远程执行，可改用可审计路径：

1. **先下载、后审阅、再运行**：手动下载 `install.ps1` / `install.sh`，通读确认无异常后再本地执行；
2. **校验和核对**：每个 Release 附带 `english-memory-method-vX.Y.Z.zip` + `SHA256SUMS`，下载后先 `sha256sum -c SHA256SUMS` 验证 zip 本身，解压后包内还有一份 `SHA256SUMS` 可二次校验全部文件；
3. **离线包安装**（全程不联网，适合内网 / GFW / 合规环境）：

   ```bash
   # Linux / macOS
   sha256sum -c SHA256SUMS                                  # 校验 zip
   unzip english-memory-method-vX.Y.Z.zip
   cd english-memory-method-vX.Y.Z
   sha256sum -c SHA256SUMS                                  # 校验包内全部文件
   ./install.sh                                             # 自动本地模式：从包内拷贝
   ```

   ```powershell
   # Windows（PowerShell 5.1+）
   sha256sum -c SHA256SUMS
   Expand-Archive english-memory-method-vX.Y.Z.zip -DestinationPath .
   cd english-memory-method-vX.Y.Z
   sha256sum -c SHA256SUMS
   .\install.ps1                                            # 自动本地模式
   ```

   安装器检测到自身位于发布包内（同目录有 `SKILL.md` / `assets/`）即自动走本地拷贝；加 `--remote`（ps1 用 `-Remote`）可强制联网安装；
4. **npm 替代**：`npx english-memory-method`（走 npm 官方源，可配合企业私有 registry）。

> 维护者：`npm run build:release` 本地产出上述 zip + 双层 SHA256SUMS（内置发布门禁：版本一致性 + 副本同一性，不过则拒绝打包）。

发版一致性要求见 [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md)。

## 📖 工作原理（15/16/17 节按文体）

| 节 | 章节 | 干什么 |
|---|---|---|
| 1 | 整体策略 | 判断文体与逻辑骨架，估算句数与背诵天数 |
| 2 | 文章结构图 | 全文压成一张 SVG 背诵地图 |
| 3 | 原文逐句精读 | 中文翻译 + 连读标注 + 专业词高亮（逐句三层） |
| 4 | 关键词串联表 | 每句 1~2 个钩子词 + 中文提示 |

| 9 | 当天三遍法 | 理解朗读 ×3 → 看钩子复述 → 看问题链复述 |
| 10 | 艾宾浩斯复习 | 5 分钟 → 睡前 → 次日 → 第 3 天 → 第 7/15 天 |

## ⚠️ 已知局限与适用边界

> 透明起见，先说清楚这份方案"在哪里会打折扣"。完整能力请见上方功能特性。

### 平台体验差异（L1 / L2 / L3）
- **L1 直装平台**（Claude Code / Codex / Trae / 通义灵码 / Comate / CodeBuddy / WorkBuddy / Kimi / MiniMax / Qwen Work / Windsurf / Continue / Roo Code 等）：功能完整——SVG 结构图 + 自包含 HTML 方案 + 逐句连读标注 + 浏览器内交互打卡/听写/影子跟读。
- **L2 规则注入平台**（Cursor / GitHub Copilot / Gemini CLI / Cline / Aider / Roo 项目级）：以 Markdown 规则注入，**输出为 Markdown 版方案，不含 SVG 结构图与可交互 HTML 组件**（打卡、听写、影子跟读等需浏览器的交互不可用）。需要完整交互体验，建议优先在 L1 平台使用。
- **L3 手动跟随**：把 `SKILL.md` 内容粘贴到自定义指令，体验取决于平台对长指令的支持程度。

### 浏览器与设备依赖
自测、听写、影子跟读依赖浏览器的 `speechSynthesis` / `MediaRecorder` / `getUserMedia` / `SpeechRecognition`：
- Firefox 的 TTS 语音列表可能为空 → 听写/朗读可能不发声（已静默降级为手动模式）。
- iOS < 14.1 不支持 `MediaRecorder` → 影子跟读录音不可用（已降级为手动自评）。
- Safari 以 `file://` 打开本地方案时，`getUserMedia` 需 HTTPS（localhost 除外）→ 录音不可用（已降级）。
- 影子跟读「🤖 自动评分」依赖 `SpeechRecognition`（Chrome / Edge 桌面版；识别在云端进行）——Firefox / Safari 无此 API，自动降级为手动自评。

进度保存在浏览器 `localStorage`：**按浏览器与 Profile 隔离**——在 Chrome 打卡后换 Edge（或另一台电脑）打开方案，进度显示为空，这不是进度丢失；官方迁移路径 = 方案页「💾 导出 / 📥 导入」JSON。Safari / iOS 配额较小，方案堆积过多可能触发写入失败（已 `try/catch` 兜底，建议定期导出备份）。**推荐固定用一个桌面浏览器完成全部打卡；移动端功能受限。**

**对话陪练读不到本机进度**：聊天里的逐句陪练与浏览器页面是隔离的，AI **读不到 `localStorage`**——默认按方案文件内容出题；只有你主动把「💾 导出」的 JSON 或薄弱句清单贴进对话，才会按到期优先排序。「🧠 标准」SM-2 的按句调度只在该 HTML 页面内部生效（打开方案 / 结束本轮 / 切到标准模式时同步），**不会跨浏览器、跨设备、也不推送到系统日历**；跨设备仍靠「💾 导出 / 📥 导入」JSON。

**📡 直推 Anki 需要本机放行**：`file://` 页面向 `127.0.0.1:8765` 发请求时 `Origin: null`，AnkiConnect 默认 CORS 配置通常不放行，需在其 `webCorsOriginList` 加入 `"null"`，或改用 `npm run preview` 以 `http://localhost:4173` 打开。探测失败（Anki 未启动 / 插件 2055492159 未装 / 端口不符 / 超时）会弹诊断并**自动回退 CSV 导出**，离线使用完全不受影响。

### FAQ
**Q：为什么我在 Cursor / Copilot 里看不到 SVG 图和打卡按钮？**
A：这些是 L2 平台，输出为 Markdown 方案，不含可交互 HTML 组件。需要完整体验请用 L1 平台。

**Q：打开方案后朗读 / 录音没反应？**
A：检查浏览器是否支持对应 API（见"浏览器与设备依赖"）。Firefox 可能不发声，iOS 旧版不能录音，Safari 本地文件不能录音——均会自动降级为手动模式。

**Q：进度会丢吗？**
A：进度存在浏览器 `localStorage`，清缓存 / 换浏览器 / 无痕模式会丢失。建议用导出（JSON）备份，并避免 Safari / iOS 小配额下堆积过多方案。

**Q：装完要不要重启？**
A：不需要。装完直接丢一篇英语文章 + 一句"出背诵方案"即可。
