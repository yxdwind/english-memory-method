# 🧠 english-memory-method

**把"背英语文章"从死记硬背，变成一条能走完的路。**

丢给它任何一篇英语文章，它还你一份完整背诵方案（普通文章 15 节 · 演讲稿 16 节含骨架 · 长文 17 节含分段仪表，自包含 HTML）：
逐句连读标注、钩子焊成问题链、复述五级阶梯、今日排期与自测模式、记忆宫殿与听写验证——全在一份文件里；背过的多篇方案还能汇总成**个人记忆库**（书架 / 搜索 / 轻刷）。

## ✨ 功能特性

| | 功能 | 一句话说明 |
|---|---|---|
| 🧠 | **链式复述** | 钩子焊成问题链：每一环由上一环推出，**能推出来的不用背** |
| 📖 | **逐句精读** | 中文翻译 + 全现象连读标注（⌒ 连读 / 弱读 / flap t / h 击穿）+ 专业词高亮 |
| 📚 | **专业词汇梳理** | 构词拆解（词根词缀）+ 音标 + 记忆钩子——认得词根，生词变熟词 |
| 💬 | **短语生活例句** | 每条搭配配一个纯英文日常例句，**直接模仿开口**（不带翻译，逼英语思维） |
| 🗂 | **15 节闭环（长文 17 节 / 演讲稿 16 节）** | 策略 → 精读 → 钩子与链 → 复述阶梯 → 三遍法 → 复习 → 自测 → 积累 → 句型 → 宫殿 → 听写 |
| 🔁 | **复习闭环** | 句级「顺/卡」打卡 → 薄弱句清单 → 连顺 2 轮毕业，进度存本地不丢 |
| 📅 | **今日排期** | 开始日期 + 按段艾宾浩斯自动算"今天背什么"，逐段勾选，一键导出日历提醒 |
| 🙈 | **自测模式** | 一键盖住翻译与连读注解再复述，点句临时揭开——防"看着答案"的假流利 |
| 🪜 | **阶梯追踪** | 每段 L1~L5 复述等级随背随记、升级留痕——跳级即假流利 |
| ✍️ | **亲手改造留白** | 每段主线、宫殿画面可亲手改写（生成效应），打印后可手写 |
| ⚡ | **薄弱句快刷** | 一键只刷薄弱句，5 分钟一轮；挖空自动批改，错空直通薄弱清单 |
| 🏛 | **记忆宫殿** | 25 站生活动线，每句一个站点——空间线索与钩子链互为兜底，随机丢句时「空站」直接暴露断点 |
| 🎧 | **听写验证** | TTS 逐句朗读 → 听写输入 → 逐词比对高亮，错句直通薄弱清单 |
| 💎 | **金句句型库** | 每篇 5~9 条可迁移句型（加粗可替换部分 + 换装模板），背了直接用进写作/演讲 |
| 🎤 | **演讲稿模式** | 自动识别三幕骨架（开场钩/论点/升华），附朗读要点；问题链与复述阶梯按演讲特点改造 |
| 📜 | **长文模式** | 500~2000 词自动启用：分段进度仪表（🔒▶✅随打卡流转）+ 段落单元按段展开 + 按段艾宾浩斯错峰 |

| 🗄 | **个人记忆库** | 所有背过的方案汇成一个 HTML：书架 / 搜索 / 轻刷（链回忆→挖空→结算）+ 进度实时读取 |

## 🚀 快速开始

**Windows（PowerShell）**：

```powershell
irm https://cdn.jsdelivr.net/gh/yxdwind/english-memory-method@main/install.ps1 | iex
```

**macOS / Linux**：

```bash
curl -fsSL https://cdn.jsdelivr.net/gh/yxdwind/english-memory-method@main/install.sh | bash
```

**Claude Code（零命令行）**：

```
/plugin marketplace add yxdwind/english-memory-method
/plugin install english-memory-method
```

**npm / npx**：

```bash
npx english-memory-method
```

> 安装器自动探测本机**全部已装平台**并逐一装入（16+ 平台别名见[平台支持](#-平台支持)）。
> jsdelivr 不通时换官方源：`irm https://raw.githubusercontent.com/yxdwind/english-memory-method/main/install.ps1 | iex`

**触发**：丢一篇英语文章 + 一句"出背诵方案"（或"出记忆技巧"）。装完无需重启。

## 📖 工作原理（15/16/17 节按文体）

| 节 | 章节 | 干什么 |
|---|---|---|
| 1 | 整体策略 | 判断文体与逻辑骨架，估算句数与背诵天数 |
| 2 | 文章结构图 | 全文压成一张 SVG 背诵地图 |
| 3 | 原文逐句精读 | 中文翻译 + 连读标注 + 专业词高亮（逐句三层） |
| 4 | 关键词串联表 | 每句 1~2 个钩子词 + 中文提示 |
| 5 | 链式化问题链 | 钩子焊成 4~7 个路标问题——复述时自问自答 |
| 6 | 复述五级阶梯 | L1 看钩子 → L2 看问题链 → L3 看标题 → L4 空手 → L5 转述他人 |
| 7 | 当天三遍法 | 理解朗读 ×3 → 看钩子复述 → 看问题链复述 |
| 8 | 艾宾浩斯复习 | 5 分钟 → 睡前 → 次日 → 第 3 天 → 第 7/15 天 |
| 9 | 挖空自测 | 每段挖 2~5 空，答案折叠、先填后核对 |
| 10 | 必背短语清单 | 8~15 条搭配 + 真实语料例句，可直接迁移 |
| 11 | 专业词汇梳理 | 构词拆解 + 音标 + 记忆钩子 |
| 12 | 金句句型库 | 可迁移句型四列表：句型 / 释义 / 可替换模板 / 使用场景 |
| 13 | 记忆钩子 | 文内语言钩 + **三层钩子链**：段钩 → 句钩链（逻辑桥串联）→ 英文锚点，逐句放行 |
| 14 | 复述技巧包 | 10 条纯技巧：卡壳自救 / 表达提速 / 练习要领 |
| 15 | 记忆宫殿映射 | 25 站生活动线，每句一个站点——空间线索兜底随机丢句 |

**📚 个人记忆库（v2.17.0）**：说一句「更新记忆库」，把工作区全部 `*-memorization-plan.html` 汇成一份自包含的 `memory-library.html`——书架卡片（标题 / 文体 / 词数 / 进度条 / 薄弱句数）实时读取本机打卡进度（同源 localStorage，零同步代码），支持标题与内容搜索；每篇可进「轻刷」：问题链逐钩回忆 → 关键句挖空挑战 → 结算并建议回原方案补打卡。轻刷结果不落盘，打卡与薄弱清单永远以原方案为准。

**核心理念**：孤立钩子 = 断点——钩子要背、顺序要背、映射也要背，三重负担。
v2 把钩子焊成链：每一环由上一环"推"出来，**能被逻辑推出的内容不需要背**。

**v2.5.0**：专业词汇音标升级为三地标注——默认美音，英音差异另起 `UK:` 行，印度发音按系统规则标 `IN:` 行；189 个术语全量标注（57 处英美差异、68 处印度音）。

**v2.8.1**：宫殿×打卡联动补全——「结束本轮」结算时薄弱句对应站点自动标红，连顺毕业同步取消；打开文件按存档恢复标红，宫殿区始终反映当前薄弱站。

**v2.9.0**：听写验证模式——逐句区新增「🎧 听写模式」：浏览器美音 TTS 逐句朗读（零配置），输入听到的句子，逐词比对高亮（错词黄/漏词红/多词灰/正确绿），错句自动进薄弱清单，与打卡、宫殿红站三线联动；听写进度独立存档，打印自动隐藏。30 篇方案全量内置。
